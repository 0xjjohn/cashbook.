دفتر - تطبيق ويب (PWA)

الملفات:
  index.html            التطبيق كله
  manifest.webmanifest  بيانات التطبيق (الاسم والأيقونات)
  sw.js                 بيخلي التطبيق يشتغل من غير إنترنت
  icons/                الأيقونات

الرفع (اختار طريقة واحدة، وكلها مجانية ولازم الرابط يبدأ بـ https):

أ) Netlify Drop (الأسهل، من غير حساب GitHub)
  1. افتح app.netlify.com/drop
  2. فك الضغط عن الملف، واسحب فولدر dafter-pwa كله على الصفحة.
  3. هيديك رابط. افتحه من الموبايل.

ب) GitHub Pages
  1. اعمل Repository جديد (Public) وارفع كل الملفات والفولدر icons بنفس ترتيبها.
  2. Settings ← Pages ← Source: Deploy from a branch ← main ← / (root) ← Save.
  3. بعد دقيقة الرابط هيكون: https://اسم-المستخدم.github.io/اسم-الريبو/

التثبيت على الموبايل:
  آيفون (Safari): زرار المشاركة ← إضافة إلى الشاشة الرئيسية.
  أندرويد (Chrome): قايمة الـ⋮ ← تثبيت التطبيق.

ملاحظات:
  - البيانات بتتحفظ على نفس الجهاز والمتصفح اللي بتفتح منه الرابط، ومفيش مزامنة بين جهازين.
  - لو مسحت بيانات المتصفح هتتمسح بيانات دفتر.
  - لما تحدّث index.html، غيّر رقم VERSION في أول sw.js (مثلا dafter-v2) عشان الموبايل ياخد التحديث.
